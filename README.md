# Codex Quota Bar

一个原生 macOS 菜单栏小工具，用来查看当前 Codex 账户的 **5 小时限额**和**每周限额**。支持 macOS 13 及以上；交付的应用按当前 Mac 的架构构建。

## 使用

1. 双击 `dist/Codex Quota Bar.app`。菜单栏采用 **A「细框分栏」**样式，以 **15 pt macOS 默认系统字体（常规字重）**显示两个百分比；外侧为 **0.5 pt 无填充细边框、3.5 pt 小圆角**，中间使用短竖线分隔。两个数值等宽居中，较长读数自动扩宽。**左侧为 5 小时限额，右侧为每周限额**，默认表示**剩余**百分比，数值随账户变化。两个数值分别按当前显示百分比着色：**10%–20%（包含边界）为黄色，低于 10% 为红色**，其他数值使用系统文字颜色；浅色背景采用深金黄色以提高可见度。悬停时可查看完整标签。
2. 点击菜单栏，弹窗采用 **02「双环仪表」**：左侧为 5 小时限额，右侧为每周限额；环内显示百分比，下方显示重置倒计时和本地时间。环形保留原有配色，始终按**剩余额度**判断：**高于 25% 为绿色，10%–25%（不含 10%）为橙色，10% 及以下为红色**；切换剩余／已用只改变环形占比及读数，不反转风险颜色。弹窗宽度为 340 pt，保留 16 pt 外圆角。
3. 可切换“剩余额度 / 已用额度”；齿轮菜单可设置“登录时启动”、选择 Codex 路径或退出。

每 60 秒刷新，点击面板、手动刷新或电脑唤醒时也会读取最新数据。菜单栏的 `!` 表示上次刷新失败或重置时间已到、数据待同步。缺失数据用 `—` 表示，不推断为 100%。网络异常时保留上次结果，并显示更新时间与错误说明。

建议将应用移动到一个固定的位置后，再开启“登录时启动”。如果系统要求批准，到 **系统设置 → 通用 → 登录项** 中允许。此开关默认关闭。

## 前提与账户

- 本机已有通过 ChatGPT 账户登录的 Codex 桌面端或 Codex CLI。API Key 登录不提供这里显示的订阅额度。
- 优先查找桌面端内置 CLI，然后查找 Homebrew、`~/.local/bin` 和 PATH；可以在齿轮菜单中指定路径。
- 使用所选 CLI 的本地 Codex 登录和配置（默认 `~/.codex`，也遵循继承的 `CODEX_HOME`）。如果桌面端与 CLI 使用不同账户或不同 `CODEX_HOME`，请先统一登录环境。此工具不实现账户切换。
- 只识别服务实际返回的 300 分钟和 10080 分钟窗口；未返回的窗口显示未知。

## 数据来源与隐私

通过本机 `codex app-server --listen stdio://` 调用官方的 `account/rateLimits/read`，采用 `rateLimitsByLimitId.codex`，兼容旧版 `rateLimits`。剩余百分比为 `100 - usedPercent`；重置时间来自服务端 `resetsAt`。

工具不读取或复制登录令牌，不保存额度到磁盘，也不发起模型对话、创建聊天或调用 `turn/start`。Codex 自身负责认证、联网和本地状态数据库维护。偏好设置仅保存显示模式和自定义 CLI 路径；额度查询仍需要网络。独立启动的 app-server 不订阅桌面端内部事件，因此以定时轮询保持更新。

官方接口文档：[Codex App Server](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)。这是独立本地工具，不是 OpenAI 官方插件。

## 从源码构建与验证

需要 Apple Command Line Tools（`xcode-select --install`），无需 npm 或其他第三方依赖。

```bash
cd codex-quota-bar
bash test.sh
bash build.sh
open "dist/Codex Quota Bar.app"
```

`build.sh` 会在项目内的 `dist/` 生成应用并进行本地 ad-hoc 签名，编译缓存和测试文件放在 `.build/`。没有 Developer ID 公证；传到其他 Mac 时需按系统提示允许打开，或在目标 Mac 重新构建。移动应用后请重新设置登录项。

只读联网诊断，不启动菜单栏：

```bash
"dist/Codex Quota Bar.app/Contents/MacOS/CodexQuotaBar" --check
```

`test.sh` 使用本地伪 app-server 验证多额度桶选择、缺失窗口、边界百分比、分片 JSON、通知穿插、登录错误、进程退出和超时清理，不访问真实账户。

## 卸载

在齿轮菜单中关闭“登录时启动”，退出并删除应用即可。源代码可单独保留。
